# Contributing

Thanks for helping keep these guides correct. Corrections matter more than new content.

## Report a problem

Open an issue using the "Outdated or broken command" template. Include:

- The guide and section, and the exact command or statement.
- What happened instead, with the error output.
- The OS and version you ran it on (for example, Ubuntu 24.04), and the `claude --version` output if it is about Claude Code.
- A link to the official documentation if a limit or behavior changed.

## Send a pull request

- Keep it small and focused: one guide fix, one new template, or one new troubleshooting entry.
- Every command should be copy-pasteable and tested on a clean Debian or Ubuntu machine. Say which version you tested on.
- Claims about third-party products need a link to their official documentation.
- Keep it neutral. No referral links, no price lists that will go stale, no marketing copy.
- Put "Last updated: YYYY-MM" at the top of any guide you change.
- Config templates start with comments that say what the file is for, how to install it, and what to edit.
